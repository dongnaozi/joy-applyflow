# Changelog

## 1.0.1 — 2026-10-30

- Times New Roman for English UI text, plain scientific notation, and a compact university search toolbar.
- Compact JoyFlow navigation and profile-derived initials; nine saved accent palettes.
- Simplified literature search with optional advanced filters and no time-range selector.
- Obsidian panel with local vault connection, read-only sync preview, incremental managed-section updates, preserved personal notes, URI links and Markdown ZIP export.
- QS 2026 top-100 university discovery scope, complete university coverage ledger, additional sourced supervisors, and an all-records option preserving the existing shortlist.
- 106 additional sourced supervisors: 130 total, including 121 associated with 79 QS 2026 top-100 universities across the supported research directions. Remaining university coverage is shown as pending, rather than complete.
- Compatible version-1 personal backups and the existing browser storage key; private CVs, application records and Obsidian files stay outside the public release.

## 1.0.0 — 2026-10-29

Initial open-source release of Joy ApplyFlow.

- Local supervisor discovery with public-source profiles, selected papers, academic relationships and QS 2026 ranking context.
- Configurable research keywords and coordinated discovery filtering.
- Browser-local resume extraction and keyword direction matching.
- Application shortlist, preparation and per-supervisor checklists, stages, follow-up dates and notes.
- RSS / Atom literature tracking with source status and local cache.
- Optional public-profile structuring through supported local Ollama models.
- Personal JSON backup / restore and application CSV export.
- Environment configuration, private runtime separation, fictional examples and project documentation.

Outreach logs, school / program deadline reminders, material tracking, draft versioning and optional SQLite persistence remain planned. Existing follow-up dates do not send reminders.
