# Changelog

## 1.0.0 — 2026-10-29

Initial open-source release of Joy ApplyFlow.

- Local supervisor discovery with public-source profiles, selected papers, academic relationships and QS 2026 ranking context.
- Configurable research keywords and coordinated discovery filtering.
- Browser-local resume extraction and keyword direction matching.
- Application shortlist, preparation and per-supervisor checklists, stages, follow-up dates and notes.
- RSS / Atom literature tracking with source status and local cache.
- Optional public-profile structuring through supported local Ollama models.
- Personal JSON backup / restore and application CSV export.
- Environment configuration, private runtime separation, fictional examples and project documentation.

Outreach logs, school / program deadline reminders, material tracking, draft versioning and optional SQLite persistence remain planned. Existing follow-up dates do not send reminders.
