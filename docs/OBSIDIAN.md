# Obsidian 联动

工作台支持连接本机 Obsidian 仓库、预览并增量同步导师与论文资料，在工作台查看仓库内的个人笔记，也可下载 Markdown ZIP 或用原生 URI 打开笔记。无需安装社区插件或提供 API 密钥。

## 从 GitHub 借鉴的功能

| 项目 | 已核实的功能 | 工作台中的实现 |
| --- | --- | --- |
| [Local REST API](https://github.com/coddingtonbear/obsidian-local-rest-api) | 读取与更新笔记，针对指定分段修改，条件写入 | 浏览器连接本地目录；只读差异预览；确认后增量写入；冲突跳过 |
| [Advanced URI](https://github.com/Vinzent03/obsidian-advanced-uri) | 笔记深链接、打开文件、按段追加、属性标识文件 | 原生 URI 打开仓库与笔记；稳定条目标识与带 ID 后缀的文件名 |
| [Zotero Integration 模板](https://github.com/community-archive/obsidian-zotero-integration/blob/main/docs/Templating.md) | 论文模板与 persist 区段保留手写内容 | 论文阅读提纲、来源属性、导师与论文双链；同步保留个人笔记 |

这些项目用于研究功能与交互方式。本项目的本地文件实现独立编写，未复制社区插件代码。当前不包含 Zotero 连接、PDF 批注导入、REST API、后台监听或 Obsidian 任务回写工作台。

## 连接与同步

1. 在 Obsidian 桌面版创建或打开自己的仓库。
2. 在工作台的 **Obsidian** 板块点击 **选择本地仓库**，选择包含 `.obsidian` 文件夹的仓库根目录。浏览器先请求读取权限。
3. 确认仓库名称及笔记目录，例如 `JoyApplyFlow`。名称用于原生 URI 打开；目录只能是仓库内相对路径。
4. 选择“我的收藏”或“当前研究方向”，点击 **预览同步**，查看新增、更新、无变化与冲突。
5. 点击 **确认同步**，浏览器请求写入权限。只有这一步会将资料写入指定笔记目录。

目录连接使用浏览器的 [File System Access API](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access)，适合在本机 `http://127.0.0.1` 使用 Chrome 或 Edge。仓库句柄仅保存在当前页面内存，刷新后需重新连接。工作台不会读取其他仓库文件或修改 `.obsidian` 配置。

不支持目录 API 的浏览器仍可 **下载笔记包**，解压后手动放入仓库。ZIP 不会自动合并旧笔记，重复导入前需自行备份与处理同名文件。

## 保留手写笔记

新笔记分为来源属性、带校验标记的工作台受管区和个人笔记区。导师、论文、索引和申请清单通过 `[[双向链接]]` 连接。

- 在 **我的阅读笔记** 中记录研究问题、催化剂与实验条件、关键证据与局限，以及和自己课题的联系。
- 在 **我的导师笔记** 中记录研究契合点、联系记录和下一步。
- 同步只替换工作台受管区，保留属性区和个人笔记区。来源与论文信息应以受管区中的最新资料为准。
- 不要手改受管区。如有修改、校验标记不完整、身份标识变化或遇到旧版无标记文件，该篇会显示冲突并跳过。
- 预览后文件发生变化也会跳过。同步逐篇执行，遇到冲突或权限错误时已写入的其他笔记不会回滚；结果报告成功与跳过数量。

**我的笔记** 从连接的仓库读取该篇个人笔记区，在工作台显示原始 Markdown。它不会将勾选任务或文字自动写回工作台的申请清单。旧版笔记建议先备份、整理到其他名称，再生成新版；不会自动迁移覆盖。

同步不执行删除操作：取消收藏不会删除仓库里的历史笔记，笔记改名后可能保留旧文件。当前浏览器在写入前复核内容，并尽可能使用独占写入句柄；它不是其他编辑器的全局事务锁，操作期间请避免同时编辑正在同步的受管区。

## 范围与个人数据

“我的收藏”包含跨研究方向收藏的导师与导师论文。文献追踪只导出当前已加载并仍可取得完整记录的收藏；收藏 ID 无法恢复不在缓存中的题录。切换方向、进入文献板块加载后可再同步其他文献。“当前研究方向”只包含本次筛选结果。

申请概览含个人准备任务、阶段、跟进日期与备注，不含背景和简历原文。导出文件及同步笔记属于个人数据，应保存在自己的仓库与备份中。读取的笔记内容不会上传网络。

**打开** 使用 [Obsidian 原生 URI](https://help.obsidian.md/Extending+Obsidian/Obsidian+URI)，需要先同步或导入文件。未连接目录时仍保留原生 **新建**，不设置 `overwrite` 或 `append`。浏览器只能发出请求，无法确认 Obsidian 是否成功打开；较长新建内容提示改用同步或 ZIP，内容不截断。
